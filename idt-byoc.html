IDT BYOC CPaaS

I helped to create the platform that provides global SIP trunking services for efficient call management and control. The platform enables users to upgrade or replace their current telephone system, allowing them to make IP-based phone calls instead of classic phone lines. Moreover, it simplifies operator integration with well-known platforms like Microsoft Teams, Twilio, and Plivo.

Outcomes

12%
users engaged with the BYOC console within the first few days after launch, validating the demand and usability of the tool.

Task

Design an MVP for Bring Your Own Carrier platform that leverages the capabilities of Twilio's SIP Trunking and improve the user experience.

This is what the Twilio platform looks like:

Process

In collaboration with the lead developer, we compiled a user story and identified the necessary features that should be included. After that I added all the tasks in Jira and started making the design for the platform.

Dashboard

After a comprehensive analysis of the competitive platforms and consultation with stakeholders, I decided to add quick access blocks to the dashboard. These blocks serve as quick creation of a new Trunk, a copy of the API, view balance information, and reports on the number of calls and minutes spent. The addition of these blocks has made the dashboard more user-friendly and efficient, allowing users to easily access the information they need without having to navigate through menu.

Managing Trunks

I have created a comprehensive user flow for trunk management. Within this section, users are able to generate trunks by using a variety of methods, including IP addresses, credential lists, tokens, or Twilio accounts. Furthermore, trunks can be effortlessly deleted and their usage can be tracked through an activity log.

CDR (Call Detail Record)

Furthermore, I designed the CDR (Call Detail Record) feature that enables the user to monitor and save call details such as duration, location, call status, and cost. This attribute played a critical role in the project as it facilitated the analysis of call data and enhanced the user experience.

Users can also filter calls by date or phone number. To make it easier to identify call results, the statuses are displayed in color, allowing users to quickly assess how the call went.

Billing

I designed the billing screens with the aim of providing users with a convenient way to access and oversee their account balances and payment history.
